Vibe Coding

Vibe coding is a conversational way to build software: describe the intent, let an AI coding tool draft the code, run it, inspect the result, and keep refining. 바이브 코딩은 만들고 싶은 방향을 자연어로 설명하고, AI가 만든 코드를 실행하며 결과를 보면서 반복 개선하는 방식입니다. 

prompt:
"Create a clear intro page about vibe coding in Korean and English."
01 Describe the outcome in plain language.
02 Review, test, and guide the generated code.
03 Iterate until the software matches the intent.

한국어

  • 바이브 코딩은 대규모 언어 모델에게 프로젝트나 기능을 자연어로 설명해 코드 생성을 맡기는 AI 보조 개발 방식입니다.
  • 이 표현은 2025년 2월 안드레이 카파시가 AI 코딩 도구와 대화하듯 작업하는 흐름을 설명하며 널리 알려졌습니다.
  • 빠른 프로토타입 제작과 반복 실험에 유용하지만, 보안, 유지보수성, 테스트 검증은 사람이 책임 있게 확인해야 합니다.

English

  • Vibe coding uses large language models to turn natural-language intent into working source code.
  • The term became widely associated with Andrej Karpathy in February 2025 as AI coding tools made conversational development more common.
  • It can speed up prototypes and exploration, but human review, tests, security checks, and maintainable design still matter.
